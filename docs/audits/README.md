# Historical Audit Chronology

The files in this directory are retained as provenance.  They are not all
statements about the current tree; several findings are superseded by later
revisions.

- `Qab9_audit_report.md`: audit of the upper-range partial proof bundle.
- `Qab10_audit_report.md`: audit of lower-state infrastructure before the
  residual branch was completed.
- `Qab12_audit_report.md`: historical audit that found the unjustified
  residual cap `d <= 224` in the one-nonunit branch.
- `Qab12_remaining_nitpicks_2026-06-26.md`: historical nitpicks against an
  earlier manuscript revision.
- `Qab13_audit.md`: external audit whose cleanups were folded into the current
  manuscript.
- `final_audit.md`: final pre-publication audit that prompted the manifest,
  environment, proof-contract, and disclosure cleanups.

The current tree uses the corrected residual range
`D <= 16,583`, `2 <= U <= D`, and `d <= 2601`, with four terminal state pairs,
two terminal package pairs, and eight residual modular gcd certificates.
